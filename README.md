# 薩默塞特郡精神病院醫務院長報告（1870 年度） / Somerset County Lunatic Asylum, Medical Superintendent’s Report for 1870 — Transcription Dataset

C. W. Carter Madden-Medlicott 的醫務院長報告記錄薩默塞特郡精神病院 1870 年度的收治、病房臨床觀察、病人工作與休閒活動。原刊列有三張表，並記載試行離院與照護安排。報告於 1871 年在 Wells 印行。

C. W. Carter Madden-Medlicott reports on admissions, ward observations, work, and recreation at the Somerset County Lunatic Asylum during 1870. Published in 1871, his report is a complete named section of the institution’s twenty-third annual report.

## Source and scope

Wellcome Collection, Medical Heritage Library, WLM28.BE5S69 1870–80 / b30304003, Source frames 1–8. Original publication: Twenty-third Annual Report of the Somerset County Lunatic Asylum, Wells, George Bishop, 1871, pp. 6–13. Complete medical superintendent’s report, pages 6–13 of the 1870 annual report. The opening leaf is unnumbered. The three original tables are included. One brief marked gap appears on page 9.

## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
## Transcription and review

AI-assisted reading used fixed source scans. Published text preserves printed spellings and historical terminology. Spacing may be normalized. A square (□) indicates an unresolved character. See the notes for editorial omissions and uncertain readings.
